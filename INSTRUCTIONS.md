# Building and updating Solace

See [README.md](README.md) for setup and Android build commands.

Before installing a new APK on a phone that already has Solace, follow [RELEASE_CHECKLIST.md](RELEASE_CHECKLIST.md). Keep the same application ID and signing key, and install over the current app. Do not run `cap init` or `cap add android`; this repository already contains the Android project.
